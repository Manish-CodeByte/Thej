# Vaikunta Vivaha

A responsive and interactive wedding invitation website that combines traditional South Indian wedding aesthetics with modern web design.

## Overview

Vaikunta Vivaha is a digital wedding invitation platform designed to provide guests with event details, venue information, and an engaging user experience through animations and interactive elements.

## Purpose

This project was developed as a personalized digital wedding invitation, creating a memorable experience for family and guests while showcasing modern web development techniques.

## Live Demo

https://rajalakshmi-weds-arun.netlify.app/

## Tech Stack

* HTML5
* CSS3
* JavaScript

## Features

* Responsive design for all devices
* Interactive animations
* Background music integration
* Event schedule and venue details
* Smooth navigation and user-friendly interface
